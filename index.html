🐧 تحميل Termux

🐧 ما هو Termux؟

Termux هو تطبيق محاكي طرفية (Terminal Emulator) لنظام أندرويد، يوفّر بيئة Linux كاملة بدون Root.

✨ مميزاته:

  • بيئة Linux كاملة
  • لا يحتاج Root
  • يدعم Python, Node.js, Git, وغيرها
  • مجاني ومفتوح المصدر
  • يستخدمه المبرمجون والمخترقون الأخلاقيون
⚠️ ملاحظة: Termux لا يعمل داخل التطبيقات. يجب تحميله من متجر Google Play أو F-Droid.

📥 روابط التحميل:

📱 Google Play 🤖 F-Droid (مُوصى به)

🚀 ابدأ بعد التثبيت:

pkg update
تحديث قائمة الحزم
$ pkg update && pkg upgrade
pkg install python
تثبيت Python
$ pkg install python
termux-setup-storage
منح صلاحية الوصول للملفات
$ termux-setup-storage
